# Smart Gym Management System

A simple Java Swing-based desktop application that demonstrates Object-Oriented Programming (OOP) concepts, exception handling, and GUI development.

---

# Project Structure

src/
├── GymPerson.java
├── Member.java
├── Trainer.java
├── Membership.java
├── GymService.java
└── MainGUI.java

---

# Features

- Add gym members
- Store membership information
- Display all members
- Exception handling using try-catch
- Java Swing graphical interface
- Demonstrates all four OOP principles

---

# OOP Concepts Used

- Encapsulation
- Inheritance
- Abstraction
- Polymorphism

---

# How to Compile

From the project root folder:

```bash
javac src\*.java
```

If already inside src folder:

```bash
javac *.java
```

---

# How to Run

From the project root folder:

```bash
java -cp src MainGUI
```

If already inside src folder:

```bash
java -cp . MainGUI
```

---

# Example Flow

1. Enter member information
2. Click Add Member
3. Click Show Members
4. View stored member records
